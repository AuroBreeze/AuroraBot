# 定时喊话插件

## 功能概述

定时喊话插件允许用户在QQ群中设置定时喊话任务，支持以下功能：

1. **设置定时喊话**：可以设置24小时制的时间进行喊话
2. **多任务支持**：可以设置多个喊话任务同时运行
3. **任务管理**：可以查看、启用、禁用、删除喊话任务
4. **权限集成**：集成Lssuing权限系统，需要3级权限才能使用
5. **智能检测**：每分钟检测一次需要执行的喊话任务

## 命令列表

### 基本命令格式
```
定时喊话 [命令] [参数]
```

### 具体命令

#### 1. 添加定时喊话任务
```
定时喊话 添加 HH:MM 消息内容 [星期]
```

**参数说明：**
- `HH:MM`：24小时制时间，如 `08:30`、`14:00`
- `消息内容`：喊话的文本内容
- `星期`：可选参数，1-7的数字，用逗号分隔
  - `1`=周一，`2`=周二，`3`=周三，`4`=周四，`5`=周五，`6`=周六，`7`=周日
  - 默认：每天（1,2,3,4,5,6,7）

**示例：**
- `定时喊话 添加 08:30 早上好`
- `定时喊话 添加 12:00 午饭时间 1,2,3,4,5`（仅工作日）
- `定时喊话 添加 18:00 下班了 6,7`（仅周末）

#### 2. 查看定时喊话任务列表
```
定时喊话 列表
```

显示当前用户在当前群组设置的所有定时喊话任务。

#### 3. 删除定时喊话任务
```
定时喊话 删除 任务ID
```

**注意：** 只能删除自己创建的任务。

#### 4. 启用/禁用定时喊话任务
```
定时喊话 启用 任务ID
定时喊话 禁用 任务ID
```

#### 5. 显示帮助信息
```
喊话帮助
喊话菜单
```

## 权限要求

使用定时喊话功能需要**3级权限**（群组管理员权限）。

权限级别说明：
- **1级**：系统管理员（最高权限）
- **2级**：付费用户/群组拥有者
- **3级**：群组管理员（本功能所需权限）

## 数据库结构

定时喊话数据存储在 `./store/db/timed_announcement.db` 文件中，包含以下表：

### announcement_tasks 表
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INTEGER | 主键，任务ID |
| group_id | TEXT | 群组ID |
| creator_id | TEXT | 创建者用户ID |
| message | TEXT | 喊话内容 |
| hour | INTEGER | 小时 (0-23) |
| minute | INTEGER | 分钟 (0-59) |
| days_of_week | TEXT | 星期几列表（JSON格式） |
| enabled | INTEGER | 是否启用（1=启用，0=禁用） |
| created_time | DATETIME | 创建时间 |
| last_executed | DATETIME | 最后执行时间 |

## 技术实现

### 1. 插件架构
- **TimedAnnouncement**：主插件类，处理用户命令
- **AnnouncementChecker**：后台检查器，定时检查并执行喊话任务
- **StoreAnnouncement**：数据库操作类

### 2. 集成方式
- 在 `Msg_dispatcher.py` 中注册插件
- 在 `ws_connect.py` 中启动后台检查任务
- 每分钟检查一次需要执行的喊话任务

### 3. 权限集成
- 使用现有的Lssuing权限系统
- 通过 `AuthManager` 类检查用户权限
- 需要3级权限才能使用本功能

## 注意事项

1. **权限控制**：只有拥有3级权限的用户才能使用本功能
2. **任务管理**：用户只能管理自己创建的任务
3. **重复检查**：同一时间、同一群组、相同内容的任务不能重复添加
4. **执行频率**：每分钟检查一次需要执行的任务
5. **防重复执行**：同一天内不会重复执行同一任务
